# PRスコアリングモデル

記事や番組での露出を1件ずつ0〜100点で評価し、月別・媒体別に集計するExcelモデルです。重みや配点はすべて「設定」シートにまとめてあり、導入企業ごとに自由に調整できます。

- ファイル：`PRスコアリングモデル.xlsx`
- 構成：使い方／設定／露出ログ／集計（月別推移グラフ付き）

## 解決する課題

- 広告換算額は「露出の質」を測れず、経営層への説明に使いにくい
- 掲載件数だけでは、業界専門紙での深い紹介と、社名が1行出ただけの記事が同じ1件になる
- 担当者ごとに評価の感覚が違い、期をまたいだ比較ができない

このモデルは、評価の基準を企業ごとに明文化し、誰が入力しても同じ点数になる状態をつくります。

## 点数の仕組み

| 評価項目 | 初期の重み | 採点方法 |
|---|---|---|
| 媒体影響力 | 25% | 媒体ランク（S〜D）を点数に変換 |
| 到達規模 | 15% | 部数・UU・視聴者数を対数で配点 |
| 扱いの大きさ | 20% | 主題／大きく紹介／一部で言及／社名のみ |
| キーメッセージ伝達 | 20% | 伝わった要点の数 ÷ 設定した要点の数 |
| ターゲット適合 | 10% | 高／中／低 |
| ビジュアル | 5% | 写真・ロゴの掲載有無 |
| 二次拡散 | 5% | SNS共有・転載数を対数で配点 |

- 基礎点 ＝ 各項目の点数を重みで加重平均（0〜100）
- PRスコア ＝ 基礎点 × 論調係数（初期値：ポジティブ1.0／中立0.8／ネガティブ−0.5）
- 判定：S（75以上）／A（50以上）／B（30以上）／C（0以上）／要対応（マイナス）

到達規模を対数で配点しているため、大手媒体だけが突出せず、専門媒体での質の高い露出も評価に残ります。

## 企業ごとに変えられるところ

「設定」シートの黄色セルはすべて変更できます。

1. 評価項目の重み（合計が100%でなくても自動で按分）
2. 媒体ランクごとの点数と、ランク分けの目安
3. 扱いの大きさ、ターゲット適合、ビジュアルの点数
4. 論調係数（ネガティブを0点扱いにする、などの方針も反映可能）
5. 到達規模・二次拡散の満点ライン、キーメッセージ数
6. 判定の区切り（S〜Cの下限）
7. 集計に使う媒体種別の名前

初期値は作成者による仮置きで、業界で標準化された数値ではありません。導入時のヒアリングで調整する前提です。

## 販売時の提案パターン（案）

- **導入パッケージ**：ヒアリングで重み・媒体ランクを設計し、過去6〜12か月分の露出を入力した状態で納品
- **月次運用**：露出ログの入力代行と、月次レポートの作成
- **年次見直し**：重みや媒体ランクを実績に合わせて再調整

## 注意点

- 金額に置き換える指標ではありません。期をまたいだ比較や、施策どうしの比較に使う相対指標です。
- 露出ログは300行まで計算式が入っています。足りない場合は最終行をコピーして下に貼り付けてください。
- サンプル行（No 1〜5）の媒体名は架空です。
